# JunhaoChou Knowledge Blog

- Use Astro static output, strict TypeScript, Tailwind CSS, Markdown/MDX Content Collections, Pagefind, Shiki, Mermaid and KaTeX.
- Keep all content in Git-managed files. Do not add databases, accounts, server APIs, CMS products, payment flows, or real credentials.
- Treat finance, privacy, VPS, networking and client topics as lawful use, risk awareness, compliant comparison, deployment, or troubleshooting. Do not create evasion, fraud, unauthorized-access, attack, or abuse guidance.
- Put environment-variable names only in `.env.example`; never write values for secrets, tokens, passwords, or server addresses.
- Run format, lint, `astro check`, build, link checks and Playwright tests after meaningful changes. Diagnose failures instead of weakening checks.
- Do not use destructive bulk deletion commands or overwrite unknown user files.
