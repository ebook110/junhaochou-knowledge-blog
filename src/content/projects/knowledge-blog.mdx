## 项目目标

把个人网站做成可长期维护的工程知识库：读者能够区分研究方向、项目记录和技术文章，作者则可以通过 Git 或受保护的编辑入口持续更新内容。

## 系统结构

- Astro 与 Content Collections 负责类型化内容和静态页面生成。
- Pagefind 在构建阶段生成本地搜索索引，不依赖运行时数据库。
- Decap CMS 作为 Git 编辑界面，由 Cloudflare Access 和独立 OAuth 流程保护。
- GitHub Actions 验证变更，Docker/Nginx 在受控 VPS 上提供静态文件与健康检查。

## 工程原则

项目保留公开 URL、Git 历史与可回滚发布路径。内容和配置接受自动校验，真实凭据只存在于对应平台的受控环境中，不进入仓库。
