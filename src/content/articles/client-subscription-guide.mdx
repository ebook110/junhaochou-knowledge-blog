> **先保护链接**：订阅链接通常同时包含账户标识和访问凭据，应按密码处理。不要把完整链接发到群聊、工单、公开仓库或截图中；一旦误泄露，立即在服务提供方处撤销或重新生成，再从所有客户端删除旧配置。

## 这篇文章解决什么问题

你已经从**可信且有权使用的来源**得到一条订阅链接，想把它用于自己的 Windows 或 Android 客户端。本篇只讲本地客户端中的导入、更新和检查，不提供规避网络限制、共享账户或绕过访问控制的做法。

不同客户端的按钮名称会随版本略有变化，但工作流是一致的：**新建远程订阅（或远程配置）→ 粘贴链接 → 拉取并解析 → 选择配置/节点 → 启用本机连接能力**。

## 先理解四个基本概念

| 概念                | 它是什么                                           | 你需要做什么                                         |
| ------------------- | -------------------------------------------------- | ---------------------------------------------------- |
| 订阅链接            | 服务方维护的一条私有配置入口，客户端可按需更新内容 | 仅在自己的客户端中粘贴，绝不公开                     |
| 配置或 Profile      | 客户端保存的一份远程或本地配置                     | 为它起一个不含个人信息的名称，便于区分               |
| 节点或出站          | 配置中可选的连接目标                               | 先选择一个，再查看本机状态是否正常                   |
| 更新订阅            | 客户端重新获取远程配置                             | 在服务方变更或客户端提示过期时执行；不必频繁重复刷新 |
| 系统代理 / VPN 权限 | 客户端把流量交给其本地服务处理的系统级能力         | 只在自己理解且有权限的设备上启用                     |

订阅是“配置的来源”，节点是“配置中的可选项”。从网页复制链接并不等于已经完成导入；只有客户端成功解析并显示配置内容，后续选择和启用才有意义。

## 导入前的三个检查

1. **确认来源和授权。** 使用服务提供方或组织管理员给出的入口；不要导入论坛、群聊或陌生网页转发的链接。
2. **从官方发布页安装客户端。** 核对应用名称、签名或发布者，避免使用捆绑安装包和来历不明的“整合版”。
3. **准备好脱敏截图。** 截图前把完整链接、账户名、流量配额、到期时间、服务器名称、IP 地址、二维码和设备标识全部遮挡。截图只需证明按钮位置和成功状态。

## 四类客户端的导入路径

| 平台                 | 配置入口通常在哪里                               | 成功后的下一步                               | 建议截图                         |
| -------------------- | ------------------------------------------------ | -------------------------------------------- | -------------------------------- |
| Windows: Clash Verge | Profiles / 配置文件中新增远程配置或从 URL 导入   | 更新配置，选中该配置，再检查代理页面         | 新建远程配置窗口，链接已完全遮挡 |
| Windows: v2rayN      | 订阅分组或订阅设置中添加订阅                     | 更新订阅，选择一个服务器，再检查系统代理状态 | 订阅设置和更新后的服务器列表     |
| Android: v2rayNG     | 订阅分组设置中新增订阅                           | 更新订阅，选中服务器，确认 VPN 连接授权      | 新增订阅页面和系统 VPN 授权提示  |
| 多平台: sing-box     | Profiles / 配置中新增远程 Profile 或从剪贴板导入 | 更新 Profile，设为当前使用，再查看连接状态   | Profile 列表及已启用状态         |

下面的菜单名称按常见稳定版整理。请以当前版本的官方说明和应用内实际文字为准，避免为了对齐旧教程而下载历史版本。

## Clash Verge（Windows）

1. 打开 **Profiles（配置文件）** 页面，选择新增远程配置、从 URL 导入或功能相近的入口。
2. 将授权订阅链接粘贴到 URL 输入框。名称可写成“个人订阅”或“组织网络”，不要写账户、邮箱或套餐信息。
3. 保存后执行一次 **Update / 更新**，确认该 Profile 的更新时间和解析结果发生变化。
4. 选中这个 Profile，前往 **Proxies（代理）** 或连接状态页，确认能看到已解析的项目。
5. 只有在你明确了解组织策略和设备用途时，再在应用中启用相应的系统网络功能；用完可在同一位置关闭。

**截图位置 A：** 新建远程 Profile 窗口。保留“导入方式”和“保存”按钮，输入框中的完整链接必须用不透明色块覆盖。

**截图位置 B：** 更新后的 Profiles 页面。保留成功更新时间或状态，不要露出订阅域名、流量信息或服务器清单。

## v2rayN（Windows）

1. 在主界面找到 **订阅分组**、**订阅设置** 或 **添加订阅**。不同版本可能把它放在“订阅”菜单下。
2. 新建一个订阅条目，填入仅用于识别的备注，并粘贴授权链接。
3. 保存后使用 **更新订阅** 或 **更新全部订阅**。先确认列表有内容和更新时间，再进行下一步。
4. 在服务器列表中选择一个由该订阅解析出的条目。连接前先查看客户端的本地状态或日志是否提示格式错误、认证失败或证书问题。
5. 系统代理是 Windows 层面的设置。启用或关闭都应在 v2rayN 的状态菜单中确认，不要依靠反复重装来处理故障。

**截图位置 C：** 订阅设置中的单条记录。链接栏与备注中的个人信息均遮挡。

**截图位置 D：** 更新完成后的主界面。保留“更新成功”或时间信息；将服务器名称、延迟、地址和账号相关字段打码。

## v2rayNG（Android）

1. 在首页进入 **订阅分组设置** 或通过右上角新增菜单选择添加订阅。
2. 录入用于识别的名称，粘贴授权链接后保存。应用若请求访问剪贴板，只在确认来源与当前操作匹配时允许。
3. 返回订阅列表执行更新，等待更新结束后检查是否新增了可选服务器。
4. 选择一个条目并发起连接。Android 首次启用时会显示系统 **VPN 连接请求**，这是操作系统权限提示，应确认应用名称无误后再决定是否允许。
5. 连接状态应同时在应用内和 Android 状态栏可见。断开时使用应用中的停止按钮，确认系统 VPN 图标已消失。

**截图位置 E：** 添加订阅页面，订阅 URL 完整打码。

**截图位置 F：** Android 的 VPN 授权提示或连接成功状态。不要截到通知内容、账号、运营商信息或设备序列号。

## sing-box（Windows、Android 等）

sing-box 的不同图形客户端和版本会采用 **Profile（配置）**、**Remote Profile（远程配置）** 或“从剪贴板导入”等表述。核心是把链接保存为可更新的远程 Profile，而不是把它当作一次性文本。

1. 进入 **Profiles / 配置**，选择新增 Profile；优先选择远程 URL 或订阅导入方式。
2. 粘贴授权链接并保存。若应用提供“更新间隔”，保持默认值或遵循服务方要求，不需要设置为高频刷新。
3. 对该 Profile 执行更新；解析成功后，将其设为当前使用的 Profile。
4. 查看应用的 Connections（连接）或 Logs（日志）页，确认没有持续出现解析、认证或证书错误。
5. 在移动设备上，首次启动同样需要经过系统 VPN 权限确认；在桌面端，确认退出或停止后系统网络设置已恢复。

**截图位置 G：** 新增远程 Profile 的入口和保存结果。URL、Profile 名称中的个人信息及配置内容必须遮挡。

## 更新、启用与验证的最小闭环

不要只以“列表出现了很多条目”作为成功标准。下面的闭环能把订阅、客户端和系统状态分开检查：

1. **更新成功：** 订阅或 Profile 显示新的更新时间，且没有格式解析报错。
2. **选择成功：** 当前选中的配置或服务器有明确标识。
3. **本机启用成功：** 应用状态页或操作系统状态栏出现对应的本地连接状态。
4. **停止成功：** 在应用内停止后，系统代理或 VPN 状态恢复到你的预期设置。

将这四项的状态做成一张最后的总览截图即可。它比展示完整链接或大量服务器名称更有解释价值。

## 常见问题：按层排查

| 现象                         | 优先检查                                                       | 不建议的处理方式                                 |
| ---------------------------- | -------------------------------------------------------------- | ------------------------------------------------ |
| 更新时提示链接无效或无法解析 | 链接是否完整粘贴、是否已过期、该客户端是否支持服务方提供的格式 | 从未知来源下载“转换器”或把链接发给陌生人诊断     |
| 更新成功但列表为空           | 服务方账户状态、订阅内容、应用日志中的解析提示                 | 反复新建相同订阅，导致难以判断当前使用的是哪一条 |
| 应用显示已启动但没有系统状态 | Windows 系统代理开关或 Android VPN 授权是否被拒绝              | 关闭系统安全功能、证书验证或权限控制             |
| 更新后原有配置变化           | 服务方更新了远程内容，或当前选错了 Profile                     | 直接覆盖本地自定义配置且不保留备份               |
| 链接疑似泄露                 | 立即撤销或重新生成链接，并移除各端旧 Profile                   | 仅修改客户端备注名称，继续使用旧链接             |

## 结语

把订阅链接视为可撤销的私有凭据，把客户端当作“解析、选择、启用和停止”的本地工具，流程就会清晰许多。第一次导入后记录客户端版本与截图日期；当界面有改版时，只需更新对应小节和截图，不必重写整篇文章。
